# ADR：画面を「図が主役」の作りに変える

## 決めたこと

1. 解説は `/help/` に移す。メイン画面には、操作と図と数値だけを置く（概要・節の前置き・図の説明文・範囲の注意書き・byline・プリセット解説・検証表・参考文献は help へ）。
2. 副ラベルを付けない。意味はレイアウト（グループ・並び・大きさ）、記号（t, h, ε, |ΔL|）、アイコン、値そのもの（選択肢の文）で伝える。読み上げ用の名前は `aria-label` と視覚的に隠した文字（`.sr-only`）で残す。
3. 画面は 2 列：左が図（4 面図、操作バー、初期値、エネルギーの図）、右が固定の操作盤（プリセット、数値、設定）。狭い画面では 1 列で、図を先頭に置く。
4. 操作バーはアイコンボタン（再生／一時停止、やり直し、拡大、縮小、視点を戻す）。キーボード：Space＝再生、R＝やり直し、＋／−＝拡大縮小、矢印＝回転（plan リポジトリの流儀）。
5. 色だけに頼らない（鳥取県のカラーユニバーサルデザインの指針）：天体は色・番号・形（丸、四角、三角、ひし形…）で区別する。コントラストは 4.5:1 以上、操作の的は 44px 以上、フォーカスは常に見える、動きを減らす設定を守る。
6. 見た目は、画面（アプリ）は無地の面と細い線、ヘルプは従来の論文の体裁（jsarticle 風）を保つ。

## 参考

- 鳥取県 カラーユニバーサルデザイン：明度・彩度の差、色以外（形・線の太さ・記号）でも区別、色名を文字でも。
- inuverse44/plan：Rust＋WASM を framework なしの TypeScript で操作、キーボードで全操作、元の位置を破線で見せる。
- ui-ux-pro-max-skill：コントラスト 4.5:1、フォーカス表示、prefers-reduced-motion、絵文字ではなく SVG アイコン。

## 変えないこと

計算（Rust・WASM）、要素の `id` と `data-*`（テストと `simulator.ts` が使う）、CSP（インライン style なし）。
