# 制作計画書：三体問題シミュレーター（Rust + WebAssembly）

天体が重力で引き合う「三体問題」（天体の数は 2〜8 に変えられる N 体問題）を、Rust で数値計算し、WebAssembly にしてブラウザで 3 次元に動かす。
見た目は、論文や研究室のページのように飾りの少ないものにする（白い紙に細い線の図。ダークモードにも対応）。文字は日本語の TeX 論文の標準（jsarticle）に合わせる：本文は Computer Modern Roman＋明朝体、見出しと太字は Computer Modern Sans（太字）＋ゴシック体。

## 1. 目的

| ID | 目的 |
| --- | --- |
| G-01 | 三体問題の面白さ（美しい周期解、予測できないカオス）を、触って確かめられる形で見せる |
| G-02 | 数値計算が「正しい」ことを、検証つきで示す（保存量、既知の解との一致） |
| G-03 | Rust・WebAssembly・Web ページを組み合わせて作れることを見せる |

## 3. 数値計算

| ID | 項目 | 内容 |
| --- | --- | --- |
| N-01 | 方程式 | 万有引力（ニュートン）、3 次元、天体の数 N = 2〜8。重力定数 G = 1 の無次元の単位。軟化（ソフトニング）はしない。N の上限は、色の見分けやすさを検証した配色が 8 色のため |
| N-02 | 積分法 1 | 古典的ルンゲ・クッタ法（RK4、刻み幅一定） |
| N-03 | 積分法 2 | ドルマン・プリンス法（RK45、刻み幅を誤差に応じて自動で変える）。指定の時刻に合わせて縮めただけの刻み（やり直しなし）のあとは、次の刻み幅を縮める前より小さくしない |
| N-04 | 積分法 3 | リープフロッグ法（速度ベルレ法、刻み幅一定、シンプレクティック） |
| N-05 | 保存量 | 全エネルギー、全運動量、全角運動量（ベクトル）を計算して表示する |
| N-06 | 刻み幅と許容誤差 | 刻み幅一定の方法（N-02、N-04）は刻み幅 h を、RK45（N-03）は許容誤差を、利用者が選べる |
| N-07 | 計算できる値の範囲 | 入力（S-05）の質量は 10⁻¹² 以上 10¹² 以下、位置と速度の各成分の絶対値は 10⁶ 以下、どの 2 天体の間隔も 10⁻⁹ 以上。範囲の外と、NaN・無限大は、理由を表示して拒否する（範囲の値は `sim::MIN_MASS`、`MAX_MASS`、`MAX_COMPONENT`、`MIN_SEPARATION` の 1 か所に置き、画面の文はそこから読む）。この範囲の初期状態では（相対位置の各成分は 2 × 10⁶ 以下、間隔は 10⁻⁹ 以上 2√3 × 10⁶ 以下）、次のとおり。あふれない：質量の和は 8 × 10¹² 以下、2 天体の項 m_i m_j / r は 10³³ 以下、各天体の加速度は 7 × 10³⁰ 以下、運動エネルギーと角運動量の各項は 3 × 10²⁴ 以下。0 や非正規化数に落ちない（正の下限がある量だけ）：質量の和は 10⁻¹² 以上、2 天体の項 m_i m_j / r は 2.8 × 10⁻³¹ 以上、2 天体の間の引力による加速度の大きさ m_j / r² は 8 × 10⁻²⁶ 以上。速度には正の下限がないので、運動エネルギーと角運動量の項は 0 や非正規化数になりうる。各天体の加速度も、引力がつり合えば 0 になる |
| N-08 | 出力の条件 | 計算の途中では、接近や放出で値が N-07 の範囲の外に出ることがある（軟化をしないため）。そこで次の 3 つは、範囲の外の有限の値でも条件を保つ形で計算する。重心：有限の質量と位置なら、有限で、各成分は位置の最小と最大の間にあり、Σ m_i r_i / Σ m_i との差は各成分で 10⁻¹⁴ × 位置の成分の絶対値の最大 + 4 × 2⁻¹⁰⁷⁴ 以下（2⁻¹⁰⁷⁴ は浮動小数点数の最小の刻み。非正規化数の位置では、真の値を表せないため。各質量を最大の質量で割った比から求め、位置は成分ごとに絶対値の最大で割ってから足し、重みの和の丸めで外れた分は最小と最大の間に収める）。足し合わせで打ち消し合う位置（例：±極大と極小）では、重心の値に対する相対誤差は小さくならない（浮動小数点数の和の誤差は、項の大きさに比例するため）。回転座標系：null か、有限で正規直交な軸を返す。座標系を返し（間隔 \|r\| が有限）、相対速度 Δv が有限で、r × Δv が 0 でないときは、z′ は r × Δv の正確な向き（各成分の差 10⁻¹² 未満）。外積は整数（BigInt）で正確に求める（浮動小数点数で求めると、途中があふれる・成分の比が極端なとき小さい成分が 0 に落ちる・ほぼ平行なとき積の丸めで打ち消し合いの残りが消える）。表示の範囲：表示の半幅は 10⁻³⁰⁰ 以上 Number.MAX_VALUE / 4 以下に収め、描画の倍率は有限で正（どの有限の位置でも、拡大・縮小を何回押しても）。NaN・無限大の点は描かない |

- 天体が近づくと加速度が急に大きくなるので、刻み幅一定の方法（N-02、N-04）は誤差が増える。これも比較で見せる（S-04）。

## 4. 構成

| ID | 構成要素 | 内容 |
| --- | --- | --- |
| C-01 | 計算部分（Rust） | 外部クレートを使わず、標準ライブラリだけで書く。積分法とシナリオ、保存量 |
| C-02 | WebAssembly の窓口（Rust） | 関数を直接公開し、天体の位置などを共有メモリの配列で渡す（wasm-bindgen などは使わない） |
| C-03 | Web ページ（Astro + TypeScript） | 軌道を 4 面図（立体図＋xy・xz・yz への投影）で描く。立体図はドラッグと矢印キーで回せる。天体の数、初期値、積分法、刻み幅・許容誤差、再生速度、カオスのずらし方（Δx, Δy, Δz）を選べる。軌跡の長さ（0〜∞、古い部分ほど薄く描く）を選べる。軌跡の点は、再生の速さと描画の頻度によらず 1/60 単位時間ごとに記録する（`src/lib/trail.ts`）。計算は描画の終わりの時刻まで 1 回で進め（記録する時刻で刻みを切らない）、途中の時刻の状態は、刻みの両端の位置・速度・加速度からの 5 次のエルミート補間で求める（`Integrator::advance_recording`）。天体 1 つあたり 20000 点を超えたら、新しい半分ほど（9999 点）は記録したときの細かさで残し、古い部分を同じくらいの細かさに間引く（いちばん古い点は残し、続いた描けない点は線を切る印として 1 点にまとめて残す）。記録できる時刻は絶対値 10⁹ まで（1/60 の倍数の番号を整数として正確に数えられる範囲）で、時刻が 10⁹ に達したら再生を止めて理由を表示する。全エネルギーの相対誤差をグラフで表示（軸のラベルは英語）。静止座標系（原点は重心）と回転座標系（原点は主星と伴星の重心、x′ 軸は主星から伴星への向き、z′ 軸は 2 天体の相対運動の角運動量の向き）を切り替えられ、主星と伴星を選べる。軌跡の各点は両方の座標系で記録する（`src/lib/rotating-frame.ts`）。L1〜L5 の位置は計算部分で求める（`scenarios::lagrange_points`） |
| C-04 | 数式と文字 | 数式は TeX で書き、ビルドの時に MathML に変換する（Temml）。数式のフォントは STIX Two Math（OFL）。本文と見出しの欧文は CMU フォント（Computer Modern、OFL）。どのフォントも使う文字だけに絞って配信し（`scripts/subset-fonts.mjs`）、最初の画面で使う 2 つは preload する |

公開先：`https://inuverse44.github.io/three-body/`（GitHub Pages）
